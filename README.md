# tube_hf_calc — 管材液压成形工艺参数计算与推荐工具

用 MoonBit 实现的**管材液压成形（tube hydroforming）工艺参数计算与推荐**工具。
面向液压成形实验与教学：输入材料、几何与工艺参数，计算安全内压区间（成形窗口）、
轴向进给补料量、壁厚减薄率，并基于参数给出有益/有害皱纹的初步判断与安全系数评估。

> 本工具是**领域专用**的工艺计算工具，不是通用力学/数值库。MoonBit 生态现有的 MoonMech、
> LunaFlow 等均为通用层，本工具填补"液压成形工艺"这一垂直空白。

## 安装与运行

```bash
moon run cmd/main   # 用示例参数跑一遍完整演示（DC04 管 60×2，进给 40mm）
moon test           # 运行全部单元测试（当前 30 个，全通过）
moon build --target wasm   # 编译为 WASM，可嵌入网页免安装运行
```

## 公式来源与物理依据

- **破裂极限内压**：管材环向应力薄膜理论（Tresca 屈服准则）
  `σ_θ = pD/(2t)`，破裂条件 `σ_θ ≥ σ_y` ⇒ `p_burst = 2tσ_y/D`。
  量纲核对：`[MPa] = mm·MPa/mm`，正确。
- **壁厚减薄率**：塑性体积守恒 `ε_c + ε_a + ε_t = 0`，其中
  `ε_c = ln(D_b/D_0)`（周向，拉）、`ε_a = -feed/L_0`（轴向，压）、
  `ε_t = -(ε_c+ε_a)`，减薄率 `= 1 - exp(ε_t)`。无进给时退化为 `1 - D_0/D_b`。
- **推荐补料量**：胀形段几何体积守恒（假设壁厚不变）
  `feed_opt = ((D_b/D_0)² - 1)·L_b`。
- **起皱下限内压**：薄壁管轴向受压失稳临界内压的量纲估计
  `p_wrinkle = α·σ_y·(t/D)`，`α` 为经验形状因子（默认 1.0，待按教材核对）。
  文献对照：Bogojavlenski & Serjakow 的 T 型接头防皱经验式
  `P_min = (0.13 + 1.15·t/D)·σ_y`（见 `wrinkle.mbt` 注释，供校准参考）。
- **皱纹分类**：基于 Yuan et al. (2003) 提出的"有益皱纹 (beneficial/useful wrinkle)"范式——
  早期"高进给 + 相对低压"引入受控皱纹储料、后期增压熨平；据此做有益/有害/过度判定。
  阈值与严格界定属课题核心，需结合《现代液压成形技术》与 ABAQUS 标定结果校准。

> ⚠️ 经验系数（材料常数、`α`、皱纹分类阈值）均为近似/外推值，提交与生产使用前
> 务必对照《现代液压成形技术》及材料手册核对。代码以 `TODO` / 注释明确标注待核对处。
